# SofronioDRS(中文说明)

[English README](README.md)

ESP32-S3 咖啡秤固件，支持 BLE、两种称重/萃取模式，以及中英文双语菜单。

本固件可运行在 **Decent HDS(Half Decent Scale)硬件** 上，与 Decent Open Scale 使用同一块板:
ESP32-S3N16、ADS1232 24 位 ADC、SH1106 OLED、BMA400 加速度计、TP4056 充电、CH340K USB 串口、
REF5025 基准、2kg 称重传感器。默认 PlatformIO 环境为 **PCB v8.1**，其他版本(v8.0 / v7.5 / v7.2
/ 原 ESP32 板)在 `platformio.ini` 中也有对应环境。

当前固件版本:**6.2.0** · 默认 PCB:**8.1**
发布说明见 [CHANGELOG.md](CHANGELOG.md)(中英文)。

---

## 功能

- **BLE Decent Scale 协议**:重量通知、去皮、计时、LED/电源、校准，以及自定义的重量校准/容器命令
- **两种咖啡制作模式**:**手冲**与**意式**。先在称重模式下称好咖啡粉，进入萃取模式后以该重量作为粉量；称重模式下长按右键 `[]` 切换咖啡模式
- **两种称重模式**:**纯称重**与**萃取**。纯称重用于称粉、容器扣除和日常称重；短按左键 `O` 进入萃取模式，并把当前读数作为粉量
- **手冲萃取**:出现液重后自动开始计时；显示实时流速(g/s，每秒刷新)和粉水比(`1:x`，液重 ÷ 粉重)，稳态后移出杯子(下降 >50g)自动停止计时
- **意式萃取**:放杯自动清零并开始计时；显示实时流速和粉水比，停止落液且读数稳定后自动停止计时
- **两级分类菜单**:中英文运行时切换(EEPROM 保存)
- **引导式校准**:稳定性捕获、范围/符号校验、校准后复核(openscale 逻辑)；也可通过实际重量校准
- **容器重量**:记录、清除、自动扣除
- **连续漂移补偿**:关闭 / 0.05 / 0.075 / 0.1 / 0.2g
- **ADS1232 采样**:可选 1/2/4 采样平均，校准使用 16 采样
- **WiFi OTA**(ElegantOTA)
- **Web UI**:网页校准、容器、按钮操作、Logo 上传/下载/恢复、JS 插件
- **WiFi 配网**:新建热点 / 加入 WiFi，配网成功后自动关闭热点，支持 `drs.local`
- **按键保护**:菜单/校准/设备信息/Web UI 期间不会误触去皮或关机

## 编译与烧录

需要 [PlatformIO](https://platformio.org/)。

```bash
# 编译并烧录默认 PCB v8.1
pio run -e esp32s3_v8_1 -t upload --upload-port /dev/cu.wchusbserialXXX

# 串口监视(115200)
pio device monitor --port /dev/cu.wchusbserialXXX --baud 115200
```

启动日志会打印校准值、容器重量、采样数、语言等。注意:读取串口时 DTR/RTS 可能让板子处于复位
状态;用脚本抓日志时请设置 `dtr = false`、`rts = false`。

### 中文字体子集(构建期)

中文界面字体由 `tools/gen_subset_fonts.py` 在构建时按源码实际用字生成，写入
`include/generated_fonts.h`。相比三套完整 GB2312 字体(约 759KB)，子集约 23KB，
固件从 2.09MB 降到约 1.5MB。修改中文界面文案后重新编译即可自动更新。

## 使用方式

两个触摸按键:

| 按键 | 板上标识 | 代码名 |
| --- | --- | --- |
| 左键 | `O`(圆形) | `SET` |
| 右键 | `[]`(方形) | `TARE` |

### 开机与 BLE 开关

按住约 1 秒开机:

| 操作 | 结果 |
| --- | --- |
| 长按**左键 `O`** 开机 | 开机并 **BLE 开启** |
| 长按**右键 `[]`** 开机 | 开机并 **BLE 关闭** |
| 短按 | 仅在开启**快速开机**时有效(`电源 → 快速开机`) |
| USB/复位/充电唤醒 | 使用菜单保存的 BLE 设置(默认开) |

菜单 `连接 → 蓝牙` 可随时修改并保存该设置。

### 称重 ↔ 萃取

| 操作 | 结果 |
| --- | --- |
| 称重模式下短按**左键 `O`** | 进入**萃取模式** |
| 萃取模式下长按**左键 `O`** | 返回**称重模式** |
| 称重模式下长按**右键 `[]`** | 切换**意式 ↔ 手冲**(保存) |
| 称重模式下短按**右键 `[]`** | **去皮** |

萃取模式下:

| 操作 | 结果 |
| --- | --- |
| 短按**左键 `O`** | 计时开始 / 停止 / 归零 |
| 短按**右键 `[]`** | 停止计时(已停止时归零) |
| 长按**右键 `[]`** | 屏幕旋转 180° |
| 放入杯子(意式) | 自动清零并开始计时 |
| 停止落液且读数稳定(意式) | 自动停止计时 |
| 手冲稳态后移出杯子(下降 >50g) | 自动停止计时 |

两种咖啡模式都会显示实时流速(g/s，每秒刷新)和粉水比(`1:x`，液重 ÷ 粉重)，以及粉量、当前重量和计时。

### 其他按键

- **双击任意键** → 关机(菜单、校准、设备信息、调试屏、Web UI 开启时禁用)
- 称重模式下长按**左键 `O`** 切换容器扣除方式
- 长按不会触发去皮

### 进入菜单

**开机时同时按住两个按键**，直到菜单出现。菜单只在启动时进入。

| 操作 | 结果 |
| --- | --- |
| 左键 `O` | 下一项 |
| 右键 `[]` | 进入 / 选中 |
| `上一级` | 返回上一级 |
| `退出` | 退出菜单 |

开关类菜单项直接显示当前状态(如 `自动休眠:开`)，选中即切换并保存。

## 菜单

```
退出
称重
├─ 开始校准            引导式校准：选砝码 → 0g 捕获 → 放砝码 → 校验/复核
├─ 漂移补偿            关闭 / 0.05 / 0.075 / 0.1 / 0.2g
├─ 自动扣除设置
│  ├─ 记录容器重量
│  ├─ 清除容器
│  └─ 自动扣除         开/关
└─ 采样数              1 / 2 / 4(保存)

连接
├─ 蓝牙                开/关(保存；开机键位也可选择)
├─ 心跳检测            开/关(5 秒无写入断开)
├─ BLE按键             开/关(BLE 连接时是否允许物理按键功能)
├─ 新建热点            手动启动 AP + 网页(D.R.S / 192.168.1.1)
├─ 加入WiFi            扫描 → 配网 → STA(drs.local)
└─ WiFi升级

显示
├─ 蜂鸣器              开/关
├─ 屏幕翻转            开/关
├─ 时间置顶            开/关
└─ 语言                中文 / English

电源
├─ 自动休眠            开/关
└─ 快速开机            短按开机 / 长按开机

信息
└─ 设备信息            固件 / PCB / 序列号；退出返回信息子菜单
```

菜单设置保存在 EEPROM；校准(地址 0)与容器(地址 4)保持原地址，新设置追加在末尾。

## Web UI

菜单 `连接` 下有两个入口:

- **新建热点**:仅 AP 模式，SSID `D.R.S` / 密码 `12345678`，
  `http://192.168.1.1`(也支持 `http://drs.local`)
- **加入WiFi**:
  1. 设备先扫描周边网络，再启动 `D.R.S` 热点
  2. 手机连接热点，打开 `http://192.168.1.1`，选择 SSID、输入密码
  3. 设备以 AP+STA 连接；**成功**约 10 秒后关闭热点，只保留 STA，使用
     `http://drs.local` 或页面显示的 IP 访问；**失败**保留热点并显示错误，可重试
  4. 凭据保存在 NVS；页面 `Switch to hotspot` 可随时回到纯热点
  5. STA 掉线会自动恢复热点作为回退

网页功能:

- 实时重量/状态(WebSocket + 轮询兜底)
- 纯称重 ↔ 萃取切换；**萃取计时只在萃取模式可用**
- 按实际重量校准；引导式校准(全程不碰设备按键)
- 容器记录/清除
- 按钮:去皮、计时、意式/手冲、旋转、菜单、设备信息、关机
- Logo:上传 PNG/JPG(浏览器 Canvas 转 128×64 1-bit XBM)、下载当前/预览 PNG 或 XBM、
  恢复固件内置 Logo、在秤上预览；上传的 Logo 同时作为开机 Logo
- 插件:上传 `.js` 文件到 LittleFS，网页自动加载，提供 `ScaleWeb` API
  (详见 [webui-plugins.md](docs/webui-plugins.md)，示例
  [plugin-example.js](docs/examples/plugin-example.js))

USB 开发辅助命令:`web` 启停热点;`joinwifi` 启动配网流程。

> 热点是开放的可信局域网(仅 AP 密码)，请在可信环境使用。

## BLE 接口

- 服务 `FFF0`,写特征 `36F5`,通知特征 `FFF4`
- 重量通知(`0xCE`)10Hz
- 心跳:连接后客户端需至少每 5 秒写入一次

| 命令 | 含义 |
| --- | --- |
| `03 0F ...` | 去皮 |
| `03 0A ...` | LED / 关机 |
| `03 0B ...` | 计时开始/停止/归零 |
| `03 1A <mode>` | 校准(0 手动;1 智能，默认禁用) |
| `03 1C <mode>` | 蜂鸣器:`00` 关 / `01` 开 / `02` 响 |
| `03 1D <n>` | 采样:`00`=1 / `01`=2 / `03`=4 |
| `03 1E <group> <show>` | 菜单 / 设备信息 / 调试显隐 |
| `03 1F` | 重启 |
| `03 30 <float32 LE 实际重量g> XOR` | 按实际重量校准(应答 `0xB0`) |
| `03 31 XOR` | 记录当前重量为容器(应答 `0xB1`) |
| `03 32 XOR` | 查询充电/USB 状态(应答 `0xB2`:充电标志、原始电平、电池电压、USB 电压) |

帧格式、校验、示例详见 [calibration.md](docs/calibration.md)。

## USB 串口命令

CH340，**115200**，命令以换行结尾:

| 命令 | 含义 |
| --- | --- |
| `calw <g>` | 按实际重量校准(如 `calw 500`) |
| `ctr` | 记录当前重量为容器 |
| `ct <g>` | 直接设置容器重量(`ct 0` 清除) |
| `cv <factor>` | 直接写校准系数 |
| `cp <g>` / `ce <g>` | 默认手冲/意式粉重 |
| `vf <V>` | 电池电压校准 |
| `v` | 打印电池电压 |
| `tare` / `set` / `cal` / `ota` / `beep` / `reset` | 秤控制 |
| `web` | 启动/停止网页热点(开发用) |
| `joinwifi` | 启动加入 WiFi 流程(开发用) |
| `logodump` | 导出当前 Logo 的 XBM 十六进制(开发用) |

## 注意与限制

- 智能校准(`0x1A 01`)默认禁用，与 openscale 一致
- 调试信息菜单入口已移除;BLE `0x1E group=2` 的调试屏仍保留
- 本固件未编译 BLE `0x1B` WiFi-OTA;请使用菜单 `连接 → WiFi升级`
- 首次运行会初始化新增设置(语言中文、蓝牙开、自动扣除开、采样 1)，不影响校准/容器
- Logo 使用 U8g2 XBM 格式:**行优先、每行 16 字节、LSB 在左**;网页已按此格式转换
