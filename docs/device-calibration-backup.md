# 设备校准参数备份（DRS074 / PCB 8.1）

- 备份日期:2026-11-08
- 固件:FW 6.1.3(含 BLE 自定义命令 0x30/0x31)
- 备份目的:移植 openscale 标准命令前后,保留校准/容器参数,EEPROM 地址保持不变
  (`i_addr_calibration_value = 0`,`i_addr_container = 4`)

## 1. 备份时设备内的值（从串口启动日志与 BLE 应答读取）

| 参数 | 值 | 读取方式 |
| --- | --- | --- |
| 校准系数 `f_calibration_value` | **-825.65** | 串口启动日志 `Cal_Val:` / BLE `0xB0` 应答 |
| 容器重量 `f_weight_container` | **223.99 g** | 串口启动日志 `Container:` / BLE `0xB1` 应答 |

> 注:该 -825.65 应为菜单内测试操作产生（负系数在 openscale 中合法,但我们 `calw/0x30` 只接受正系数）。

## 2. 我们已验证的校准记录（57g 校准）

| 项目 | 数据 |
| --- | --- |
| 校准前读数 | 51.20 g |
| 实际重量 | 57.0 g |
| 计算出的新校准系数 | **933.4386** |
| 校准后读数 | 56.99 g（误差 -0.01g） |
| BLE 校准帧（旧命令号,已废弃） | `03 1C 00 00 64 42 39` |
| BLE 校准帧（现行命令号） | `03 30 00 00 64 42 15` |

## 3. 恢复方法

USB 串口（115200,命令以换行结尾）:

```
cv 933.4386        # 恢复 57g 校准得到的系数
cv -825.65         # 恢复本备份中的当前值（如需）
ct 223.99          # 恢复容器重量
```

或重新校准:秤上放已知砝码后发送 `calw <实际重量g>`,BLE 发送 `03 30 <float32 小端(g)> XOR`。

## 4. 注意事项

- 本文件仅记录数值备份;固件中的 EEPROM 布局（地址 0/4）未改动,重新烧录 APP 分区不会清除 EEPROM。
- 恢复 `cv` 后需 `EEPROM.commit()`（命令内部已提交）,断电重启后生效保持。
- 若加载过 openscale 固件（其存储使用 NVS 键,而非本固件的 EEPROM 地址 0/4）,两者校准值互不通用,需按本表恢复或重新校准。
