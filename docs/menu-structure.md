# 菜单结构（已实现）

两级分类菜单，每页 4 行；开关类设置单条显示状态（如 `自动休眠:开`），选中即切换并保存。
支持**中英文切换**（`显示 → 语言`），英文标签已按 128px OLED 宽度控制。

```
主菜单（6 项，2 页）
├─ 退出
├─ 称重 ▸
│  ├─ 上一级
│  ├─ 开始校准            （openscale 校准逻辑：稳定性捕获/校验/复核）
│  ├─ 漂移补偿            循环：关闭 / 0.05g / 0.075g / 0.1g / 0.2g
│  ├─ 自动扣除设置 ▸
│  │  ├─ 上一级
│  │  ├─ 记录容器重量     （与 USB ctr / BLE 0x31 同源）
│  │  ├─ 清除容器
│  │  └─ 自动扣除         开/关
│  └─ 采样数              循环：1 / 2 / 4（EEPROM 保存）
├─ 连接 ▸
│  ├─ 上一级
│  ├─ 蓝牙               开/关（EEPROM 保存，默认开；开机键位也可选择：左键开/右键关）
│  ├─ 心跳检测           开/关（5 秒无写入断开，与 openscale 一致）
│  ├─ BLE按键            开/关
│  └─ WiFi升级
├─ 显示 ▸
│  ├─ 上一级
│  ├─ 蜂鸣器             开/关
│  ├─ 屏幕翻转           开/关（主界面/菜单/校准/信息界面）
│  ├─ 时间置顶           开/关（纯称重计时显示位置）
│  └─ 语言               中文 / English
├─ 电源 ▸
│  ├─ 上一级
│  ├─ 自动休眠           开/关
│  └─ 快速开机           开/关
└─ 信息 ▸
   ├─ 上一级
   └─ 设备信息           中文/英文信息屏（固件/PCB/序列号）；退出返回信息子菜单
```

## 与原菜单的对应关系

| 原菜单项 | 现在位置 |
| --- | --- |
| 蜂鸣器设置 → 开启/关闭 | 显示 → 蜂鸣器（单项开关） |
| 自动扣除设置 → 设置容器重量 | 称重 → 自动扣除设置 → 记录容器重量 |
| 称重校准 → 开始校准 | 称重 → 开始校准（逻辑改为 openscale） |
| WiFi升级 | 连接 → WiFi升级 |
| 设备信息 | 信息 → 设备信息（新界面） |
| 开发选项 → Debug信息 | 菜单入口已移除（BLE 0x1E group=2 调试屏仍保留） |
| 开发选项 → 校准电压4.2v | **已移除**（串口 `vf` 仍可设电池校准因子） |
| 自动休眠 开启/关闭 | 电源 → 自动休眠（单项开关） |
| 快速开机 短按/长按 | 电源 → 快速开机（单项开关） |
| 漂移补偿 子菜单 | 称重 → 漂移补偿（单项循环） |

## 菜单进入方式

保持原有：**开机时按住两个按键**进入菜单。未增加运行时进入方式。

## EEPROM 新增地址（追加在末尾，旧地址不变）

| 变量 | 说明 |
| --- | --- |
| `i_addr_language` | 语言（0=中文，1=English） |
| `i_addr_bleEnabled` | 蓝牙开关（默认开） |
| `i_addr_containerSubtract` | 自动扣除总开关（默认开） |
| `i_addr_samplesInUse` | 采样数（1/2/4，默认 1） |
| `i_addr_settingsVersion` | 设置版本标记（首次运行写入默认值） |

校准（地址 0）与容器（地址 4）参数不受影响。

## 行为要点（详见 behavior-notes.md）

- 长按去皮键切换意式/手冲或旋转屏幕，**不再触发去皮**；短按去皮保持不变。
- 菜单选择、设备信息/调试界面的按键释放均不会触发去皮。
- 设备信息界面退出后回到“信息”子菜单；快速双击只关闭界面，不会关机。
- 手冲萃取：稳态（0.2g / 1s）后重量下降超过 50g，自动停止计时。
- 开机去皮只采样 1 次，避免 `SAMPLES=16` 导致启动变慢；首次运行统一初始化新设置。
- 开机 BLE 选择：左键 O/SET = 开，右键 []/TARE = 关；复位/USB 上电用保存值（默认开）。

## 双语说明

- 菜单名称通过翻译表在绘制时切换，无需重启动。
- 校准/容器/信息/调试/关机/WiFi升级等界面均已双语化。
- 英文字符串按 OLED 128px 宽度裁剪，超宽时自动降级到较小字体。
