# 行为说明（2026-11-08 更新）

本文记录本轮固件改动后与操作手感相关的行为，便于验收与回归测试。

## 1. 按键与去皮

| 操作 | 行为 |
| --- | --- |
| 短按去皮键（纯称重/萃取） | 正常去皮（保持原功能） |
| 长按去皮键（纯称重） | 切换意式 / 手冲模式，**不会去皮** |
| 长按去皮键（萃取模式） | 切换屏幕旋转，**不会去皮** |
| 菜单中用右键选择任意项 | 该次按键释放**不会去皮** |
| 进入/退出设备信息界面 | 相关按键释放**不会去皮** |

> 实现方式：菜单选择、长按、信息/调试界面会设置一次性 `b_suppressTareRelease`，消费后自动清除。

## 2. 设备信息 / 调试

- `信息 → 设备信息`：显示固件、PCB、序列号（中/英）。
- 在设备信息界面按左/右键 → **返回“信息”子菜单**（不再直接回到称重界面）。
- 设备信息/调试界面中：
  - 单击：关闭界面；
  - **快速双击：只关闭界面，绝不触发关机**；
  - 长按：只关闭界面，不切换模式/旋转。
- “调试信息”菜单入口已移除；BLE 标准命令 `03 1E 02 01` 的调试屏仍保留。

## 3. 手冲萃取自动停止

手冲模式计时中：

1. 重量在 **1 秒内变化 ≤ 0.2g** → 判定稳态，锁存当前重量；
2. 稳态后重量**下降超过 50g** → 判定为移出杯子/容器，**停止计时**；
3. 去皮完成、重新开始冲煮、计时器归零时复位该检测。

串口日志示例：

```
Pour-over stable: 302.5g
Pour-over cup removed (>50g): 302.5g -> 0.3g, timer stopped
```

## 4. 开机与设置

- 开机去皮使用 **1 个采样**，不再因 `SAMPLES=16` 多等约 1.6 秒；启动完成后恢复用户采样数设置。
- 新增设置首次运行写入默认值（语言中文、蓝牙开、自动扣除开、采样 1），通过
  `SETTINGS_VERSION=1` 标记，避免旧 EEPROM 随机字节被误认为有效设置。
- 串口启动日志新增 `Samples:` 与 `Lang:` 字段，便于确认当前设置。

## 5. 语言与菜单

- `显示 → 语言` 可切换中文 / English，EEPROM 保存，重启保持。
- 菜单名称、校准/容器/设备信息/调试/关机/WiFi升级界面均支持双语。
- 菜单采用固定行距/紧凑布局，128x64 下不裁切（测试方法见 `docs/menu-structure.md`）。

## 6. BLE

- 蓝牙默认开启；菜单可关闭（关闭后停止广播，设置保存）。
- 心跳检测默认开启：连接后 **5 秒**内没有任何写入会断开客户端（与 openscale 一致）。
- 标准命令：`0x0F` 去皮、`0x0A` 显示/电源、`0x0B` 计时、`0x1A` 校准（mode 0 手动 / 1 智能禁用）、
  `0x1C` 蜂鸣器、`0x1D` 采样设置、`0x1E` 菜单/设备信息/调试、`0x1F` 重启。
- 自定义命令：`0x30` 按实际重量校准、`0x31` 记录容器，应答 `0xB0`/`0xB1`。
  详见 [calibration.md](calibration.md)。

- [ ] 设备信息退出：回到信息子菜单
